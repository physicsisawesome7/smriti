# Getting help

| You want to | Go to |
|---|---|
| Install Smriti and ask your first question | [Quickstart](https://safearly.com/docs/quickstart) · [deploy/README.md](deploy/README.md) |
| Understand agents, tools, workflows and integrations | [docs/agents.md](docs/agents.md) · [docs/workflows.md](docs/workflows.md) · [docs/integrations.md](docs/integrations.md) |
| Connect a website, API, database or MCP server | [docs/ingestion.md](docs/ingestion.md) |
| Report a bug or ask for a feature | [GitHub issues](https://github.com/physicsisawesome7/smriti/issues/new/choose) |
| Report a security problem | [SECURITY.md](SECURITY.md) (privately, please) |
| Talk about a pilot, deployment or partnership | [lalit@safearly.com](mailto:lalit@safearly.com) · [Safearly on LinkedIn](https://www.linkedin.com/company/safeary.ai/) |
| Read about how it works and why | [safearly.com](https://safearly.com) · [blog](https://safearly.com/blog) |

When you ask for help, include:
- the version (`smriti --version`);
- how you installed it (Docker profile, or pip);
- your GPU and memory, if the question is about models;
- what you did, what you expected and what happened.

Never paste real personal data or official documents into an issue.
